# Fuad Hasan — Research & PhD Portfolio

A responsive academic portfolio based on Fuad Hasan's October 2026 research CV. Plain HTML, CSS, and JavaScript; no build step, package installation, analytics, or external font scripts.

## Deploy to Netlify or another static host

Publish the contents of `dist/`. The published root must contain `index.html`, `assets/`, and `cv/`.

Keep `cv/Fuad_Hasan_Research_CV.pdf` at its existing path or update all CV links in `index.html`. The supplied PDF is the current two-page academic CV, unchanged.

## Content

- Degree completed July 2026; CGPA 3.61/4.00.
- Three peer-reviewed conference publications; two first-author publications.
- MCBA-Net appears separately as a thesis manuscript under review.
- Professional experience and profile links follow the research CV.
- The home page uses “Prospective PhD Student” and a Fall 2027 target, without claiming current doctoral enrolment or candidacy.

Publication buttons open the DOI pages. BibTeX entries are transcribed from the CV; they include only supplied bibliographic fields. Each citation can be copied or downloaded. The theme preference is stored locally in the visitor's browser.

To update dates or manuscript status, edit the relevant content directly in `dist/index.html`. The source has no third-party runtime dependencies.
